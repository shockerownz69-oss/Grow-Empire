# BUILD.md — Grow Empire Android

How to build the Grow Empire Android app from this project.

## Project layout

```
grow-empire-android/
├── app/                        # Capacitor project root (npm)
│   ├── capacitor.config.ts     # appId com.shockerownz.growempire, plugins, splash
│   ├── package.json
│   ├── www/                    # BUNDLED game (index.html, styles.css, game.js) — gitignored, see below
│   └── android/                # Native Android project (generated by `npx cap add android`, then customized)
│       ├── keystore.properties.example   # copy → keystore.properties (NEVER commit the real one)
│       └── app/src/main/ ...   # Manifest, res (icons, splash, themes), MainActivity
├── assets/
│   ├── icons/                  # playstore_512.png, feature_graphic_1024x500.png, masters
│   └── splash_logo.png
└── docs/                       # BUILD, SIGNING, PLAY_CHECKLIST, STORE_LISTING, PRIVACY_POLICY, TERMS, REMAINING
```

## Prerequisites (build machine)

| Tool | Version | Notes |
|---|---|---|
| JDK | 17 | Required by Android Gradle Plugin. `java -version` must show 17. |
| Android SDK | API 34+ (compileSdk) | Via Android Studio **or** command-line tools |
| Android SDK cmdline-tools | latest | `sdkmanager` for headless installs |
| Node.js | 20+ | Only for `npm` / `npx cap` steps |
| Gradle | wrapper-provided | `./gradlew` downloads it automatically |

Headless SDK install (no Android Studio):

```bash
# download cmdline-tools from https://developer.android.com/studio#command-line-tools-only
sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"
# accept licenses
yes | sdkmanager --licenses
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/platform-tools
```

## Step 0 — refresh the bundled game (do this on every release)

The `www/` directory is a **copy** of the web game. Before building, always
refresh it from the source of truth:

```bash
cd grow-empire-android/app
cp ~/workspace/your_files/shocker-ownz-grow-empire/index.html www/
cp ~/workspace/your_files/shocker-ownz-grow-empire/styles.css www/
cp ~/workspace/your_files/shocker-ownz-grow-empire/game.js www/
# sanity: the game must end with </html> and pass syntax check
tail -c 20 www/index.html
node --check www/game.js
```

## Step 1 — install JS dependencies

```bash
cd grow-empire-android/app
npm install
```

## Step 2 — sync the web bundle + plugins into the native project

```bash
npx cap sync android
```

This copies `www/` → `android/app/src/main/assets/public/` and registers the
native plugins (App, Haptics, StatusBar, Keyboard, SplashScreen, Browser).

## Step 3 — build

```bash
cd android
```

**Debug APK** (install on your own devices for testing):

```bash
./gradlew assembleDebug
# output: app/build/outputs/apk/debug/app-debug.apk
```

**Release AAB** (what you upload to Google Play):

```bash
./gradlew bundleRelease
# output: app/build/outputs/bundle/release/app-release.aab
```

> The release build reads signing config from `android/keystore.properties`
> (see `docs/SIGNING.md`). Without it, the build falls back to the debug key —
> fine for local testing, **never upload a debug-signed AAB to Play**.

## Version bumps

For every new Play release, bump **both** in `android/app/build.gradle`:

```gradle
versionCode 2          // +1 every release, never reuse
versionName "1.0.1"    // user-visible; also update the in-game
                       // Settings → "Grow Empire vX.Y.Z — Shocker OwnZ" line
```

`versionCode` must increase monotonically or Play rejects the upload.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `Could not find installation of TypeScript` | `npm install` was skipped — run it (typescript is a devDependency) |
| `SDK location not found` | Set `ANDROID_HOME`, or create `android/local.properties` with `sdk.dir=/path/to/Sdk` (never commit it) |
| `keystore.properties` missing | Release still builds with debug key; create the file per `docs/SIGNING.md` before a real release |
| White screen on launch | `www/` is stale or empty — redo Step 0, then `npx cap sync android` |
| Splash stuck | The JS bridge hides it on boot; check `adb logcat` for WebView console errors |
